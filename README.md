# Modern Minimalist Frontend Application

A clean, responsive, and lightweight frontend application built with vanilla HTML5, CSS3, and modern JavaScript.

## 🚀 Features

- 📱 **Fully Responsive Layout**: Built with CSS Grid & Flexbox.
- 🎨 **Dynamic CSS Variables**: Easy theme customization.
- ⚡ **Zero Build Step**: No Node.js or bundlers required—runs directly in the browser.
- 🌐 **GitHub Pages Ready**: Integrated GitHub Actions deployment workflow.
